Privacy Policy

Last updated: October 2026 · Applies to the Convertly Chrome extension.

Convertly processes your files locally on your device. Your files are not uploaded to our servers because Convertly does not operate a file-processing server.

Your files

  • Files you open, drop or paste are read directly by your browser and processed in memory using JavaScript, Web Workers and WebAssembly that are bundled inside the extension.
  • Results are saved through Chrome's own download manager.
  • Convertly keeps no copies. When you close the Convertly tab, everything in memory is released.
  • Passwords typed to open a protected ZIP or PDF are used only in memory, on your device, to decrypt that file. They are never stored and never sent anywhere.

No network access

  • The extension pages run under a Content Security Policy that only allows the extension itself (connect-src 'self' blob: data:) — connections to external hosts are blocked by the browser.
  • Convertly loads no remote code, fonts, WebAssembly or scripts (no CDNs).
  • The tools keep working with Wi-Fi turned off.

What is stored on your device

Stored in chrome.storage.local on this device only:

DataPurpose
Preferences (theme, language, default quality, download folder, confirmations)Remember your settings
Favorite tool idsShow your favorites
Recently used tool ids + date (optional, can be disabled and cleared)"Recently used" section

File names and file contents are never stored.

What Convertly never sends

  • File names or file contents
  • Conversion history
  • Browsing history
  • Your IP address or device information
  • Telemetry, crash reports or usage statistics of any kind

No analytics or tracking SDKs are included. There are no accounts and no login.

Permissions

PermissionWhy
storageSave the preferences listed above
downloadsSave results (optionally into a sub-folder of Downloads, or with a "Save as" dialog)

Convertly requests no access to the websites you visit (no host permissions, no content scripts, no tabs permission).

Device capabilities

At startup Convertly checks locally which browser features exist (WebAssembly, workers, image encoders, number of CPU threads) to enable only the tools that can run. These values are used only on your device and never transmitted.

Open source

Convertly is free software (GPL-3.0-or-later). Anyone can verify these statements in the source code.

Contact

Questions about this policy: use the support contact listed on the Chrome Web Store page, or open an issue in the source repository.

100% Privado · Os ficheiros nunca saem do seu dispositivo

Política de Privacidade

Última atualização: outubro de 2026 · Aplica-se à extensão Convertly para Chrome.

O Convertly processa os seus ficheiros localmente, no seu dispositivo. Os seus ficheiros não são enviados para os nossos servidores porque o Convertly não tem nenhum servidor de processamento de ficheiros.

Os seus ficheiros

  • Os ficheiros que abre, arrasta ou cola são lidos diretamente pelo seu browser e processados em memória com JavaScript, Web Workers e WebAssembly incluídos na extensão.
  • Os resultados são guardados através do gestor de transferências do próprio Chrome.
  • O Convertly não guarda cópias. Ao fechar o separador do Convertly, tudo o que estava em memória é libertado.
  • As palavras-passe introduzidas para abrir um ZIP ou PDF protegido são usadas apenas em memória, no seu dispositivo, para desencriptar esse ficheiro. Nunca são guardadas nem enviadas.

Sem acesso à rede

  • As páginas da extensão correm com uma Content Security Policy que só permite a própria extensão (connect-src 'self' blob: data:) — o browser bloqueia ligações a servidores externos.
  • O Convertly não carrega código, tipos de letra, WebAssembly ou scripts remotos (sem CDNs).
  • As ferramentas continuam a funcionar com o Wi-Fi desligado.

O que fica guardado no seu dispositivo

Guardado em chrome.storage.local, apenas neste dispositivo:

DadosFinalidade
Preferências (tema, idioma, qualidade predefinida, pasta de transferências, confirmações)Lembrar as suas definições
Ids das ferramentas favoritasMostrar os seus favoritos
Ids das ferramentas usadas recentemente + data (opcional, pode ser desativado e limpo)Secção "Usadas recentemente"

Nomes e conteúdos de ficheiros nunca são guardados.

O que o Convertly nunca envia

  • Nomes ou conteúdos de ficheiros
  • Histórico de conversões
  • Histórico de navegação
  • O seu endereço IP ou informação do dispositivo
  • Telemetria, relatórios de erros ou estatísticas de utilização de qualquer tipo

Não inclui analytics nem SDKs de rastreio. Não há contas nem login.

Permissões

PermissãoPorquê
storageGuardar as preferências indicadas acima
downloadsGuardar os resultados (opcionalmente numa subpasta das Transferências ou com a janela "Guardar como")

O Convertly não pede acesso aos sites que visita (sem permissões de anfitrião, sem content scripts, sem a permissão tabs).

Capacidades do dispositivo

Ao iniciar, o Convertly verifica localmente que funcionalidades do browser existem (WebAssembly, workers, codificadores de imagem, número de threads do processador) para ativar só as ferramentas que podem funcionar. Estes valores são usados apenas no seu dispositivo e nunca são transmitidos.

Código aberto

O Convertly é software livre (GPL-3.0-or-later). Qualquer pessoa pode confirmar estas afirmações no código-fonte.

Contacto

Dúvidas sobre esta política: use o contacto de suporte indicado na página da Chrome Web Store ou abra uma issue no repositório do código-fonte.
